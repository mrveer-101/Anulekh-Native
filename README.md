# Anulekh Mobile Application (React Native + Expo)

This directory will contain the cross-platform mobile application code for Anulekh.

## Getting Started

To run the application locally and preview it on your device:

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start the Expo Dev Server**:
   ```bash
   npx expo start
   ```

3. **Preview the App**:
   - **Expo Go (Recommended)**: Download the "Expo Go" app from the App Store (iOS) or Play Store (Android). Scan the QR code printed in the terminal.
   - **Android Emulator**: Press `a` in the terminal (requires Android Studio / emulator setup).
   - **iOS Simulator**: Press `i` in the terminal (requires macOS and Xcode).
   - **Web Browser**: Press `w` in the terminal to view a web preview.
